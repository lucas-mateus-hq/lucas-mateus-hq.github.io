# Bundled web fonts

Source Sans 3 (normal, weights 400–700), Source Serif 4 (normal and italic, weight 400). Latin WOFF2 binaries are distributed as received from Google Fonts; they were not modified in this repository. See SOURCE_SANS_LICENSE.txt and SOURCE_SERIF_LICENSE.txt for the Adobe SIL OFL notices.

Upstream families: https://github.com/adobe-fonts/source-sans and https://github.com/adobe-fonts/source-serif . Retrieved 2026-10-19 from the Google Fonts CSS API, with a browser supporting WOFF2. All fonts are served locally; visitors make no Google Fonts requests.
